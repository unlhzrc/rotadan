# ROTADAN — Gezi & GPS Takip Ulaşım Günlüğü

Bu, motosiklet gezilerini GPS ile kaydetmek için hazırlanmış mobil öncelikli ilk sürümdür.

## İçinde olanlar

- Canlı konumdan rota çizimi
- Mesafe, süre ve ortalama hız hesabı
- Sürüşü isimlendirip cihazda kaydetme
- Kayıtlı gezileri listeleme
- Tüm gezileri farklı renklerde Türkiye haritasında gösterme
- Açık / koyu görünüm

## Telefonla test

Bu dosyalar bir web sunucusundan açılmalıdır; doğrudan dosyaya çift tıklamak konum iznini çalıştırmayabilir. Telefon ve bilgisayar aynı Wi-Fi ağındayken proje klasörünü yerel bir web sunucusuyla paylaşın. Chrome'da açıp konum iznine izin verin.

GPS kaydı telefon tarayıcısı açıkken çalışır. Ekran kapalıyken takip ve gerçek Android paketi, sonraki aşamada eklenecek yerel mobil uygulama sürümünü gerektirir.
